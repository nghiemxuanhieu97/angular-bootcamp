# 1. Giới thiệu

Angular Bootcamp là một giáo trình học tập hoàn chỉnh, giúp học Angular từ những nền tảng đầu tiên.

Thay vì học thuộc cú pháp, người học sẽ hiểu:

- Vì sao một concept tồn tại.
- Nó giải quyết vấn đề gì.
- Nó khác Java như thế nào.
- Angular sử dụng nó ở đâu.
- Cách xây dựng mental model chính xác.

# 2. Mục tiêu

Sau khi hoàn thành Bootcamp, người học có thể:

- Đọc và sử dụng JavaScript hiện đại một cách tự tin.
- Viết TypeScript dễ bảo trì.
- Hiểu kiến trúc Angular.
- Xây dựng ứng dụng Angular theo phong cách production.
- Tự tiếp tục học các chủ đề Angular nâng cao.

# 3. Đối tượng học

- Java Backend Developer.
- Developer mới học Frontend.
- Người tự học.
- Mentor trong team.

# 4. Triết lý học tập

Mỗi lesson đi theo quy trình:

`Story → Problem → Why → Mental Model → Syntax → So sánh Java → Angular Usage → Questions → Review`

Nguyên tắc quan trọng:

- Hiểu trước khi ghi nhớ.
- Storytelling là một phần bắt buộc.
- So sánh với Java khi hữu ích.
- Chỉ học sâu khi kiến thức đó phục vụ Angular.
- Review tập trung vào cách tư duy, không chỉ tính đúng sai.

# 6. Các file dùng chung

`README.md` — Giới thiệu, triết lý và hướng dẫn sử dụng.

`README.vi.md` — Phiên bản tiếng Việt của README.

`ROADMAP.md` — Lộ trình học tập đầy đủ.

`KNOWLEDGE_GRAPH.md` — Mối quan hệ giữa các concept.

`AGENTS.md` — Quy tắc để AI/Codex duy trì repository.

`PROGRESS.md` — Tiến độ cá nhân của người học, nếu cần.

# 7. Vòng đời của lesson

```text
Theory
  → Clarification
  → Questions
  → Learner Answers
  → Review & Feedback
  → Completed
```

# 9. Chế độ học

## Fast Mode

- Hoàn thành trọn vẹn một lesson trong một lần học.

## Deep Mode

- Viết lại các ví dụ.
- Dự đoán output.
- Tự giảng lại lesson.
- Review sau 1 ngày, 1 tuần và 1 tháng.

# 10. Nguyên tắc thiết kế

- Tài liệu có giá trị lâu dài.
- Học theo vấn đề.
- Ưu tiên so sánh với Java.
- Định hướng Angular.

# 11. Câu hỏi thường gặp

**Có thể bỏ qua JavaScript không?**  
Không. Angular được xây dựng trên TypeScript, còn TypeScript biên dịch thành JavaScript.

**Có thể bỏ qua Storytelling không?**  
Không. Storytelling là một phần của mô hình học tập.

**Tiến độ của người học nằm ở đâu?**  
Trong `PROGRESS.md` do người học tự tạo và cập nhật

# 12. Đóng góp

Khi mở rộng Bootcamp:

- Giữ nguyên cấu trúc lesson.
- Giữ nguyên storytelling.
- Giữ nguyên câu trả lời của người học.
- Không rút gọn package lesson.
- Cập nhật Knowledge Graph và Roadmap khi curriculum thay đổi.
