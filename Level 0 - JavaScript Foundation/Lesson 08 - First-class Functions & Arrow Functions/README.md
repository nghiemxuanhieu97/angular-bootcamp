# Lesson 08 - First-class Functions & Arrow Functions

## Problem
Làm thế nào để JavaScript coi Function như một value, cho phép Function được gán vào biến, truyền vào Function khác, trả về từ Function và viết ngắn gọn bằng Arrow Function?

## Learning Objectives
- Hiểu Function là một value.
- Phân biệt Function reference và Function invocation.
- Gán Function vào Variable.
- Truyền Function làm Argument.
- Hiểu Function có thể được trả về.
- Viết Arrow Function.
- Phân biệt First-class Function và Arrow Function.
- Chuẩn bị nền tảng cho Callback, Promise, Async/Await và RxJS.
