## Câu 4

Trong đoạn code sau:

```javascript
const employees = [
    {
        id: 1,
        name: "Hieu"
    },
    {
        id: 2,
        name: "Tom"
    }
];
```

* `employees` là gì?
* Giá trị của `employees` là gì?
* `employees[0]` là gì?

## Câu 6

Đoạn code sau có kết quả gì?

```javascript
const names = [
    "Hieu",
    "Tom"
];

names.push("Jerry");
```

Sau khi chạy xong, `names` có giá trị là gì?

## Câu 7

Đoạn code sau có kết quả gì?

```javascript
const names = [
    "Hieu",
    "Tom",
    "Jerry"
];

names.pop();
```

Sau khi chạy xong, `names` còn lại gì?

## Câu 8
