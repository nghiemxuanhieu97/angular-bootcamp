# Lesson 04 - Arrays

## Problem

Làm thế nào để lưu và quản lý một danh sách nhiều giá trị liên quan mà không phải tạo hàng loạt biến riêng lẻ?

## Learning Objectives

- Hiểu Array được sinh ra để giải quyết vấn đề gì.
- Phân biệt Array với Object.
- Hiểu phần tử, index và quy tắc index bắt đầu từ `0`.
- Biết truy cập phần tử bằng index.
- Biết thêm và xoá phần tử bằng `push()` và `pop()`.
- Phân biệt index với `id` của object.
- Hiểu Array có thể chứa nhiều loại value trong JavaScript.
- So sánh Array trong JavaScript với `List` trong Java.
- Liên hệ Array với dữ liệu từ API và Angular.
