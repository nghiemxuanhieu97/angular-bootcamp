# Lesson 07 - Modules (`import` / `export`)

## Problem

Làm thế nào để chia chương trình JavaScript thành nhiều file có ranh giới rõ ràng, tránh global scope, trùng tên và khó bảo trì?

## Learning Objectives

- Hiểu Module giải quyết vấn đề gì.
- Hiểu `export` và `import`.
- Sử dụng Named Export và Default Export.
- Phân biệt Named Export và Default Export.
- Hiểu một module có thể có nhiều Named Export và tối đa một Default Export.
- Đọc được các dòng import phổ biến trong Angular.
- Mô tả được luồng Module A → export → import → Module B.
