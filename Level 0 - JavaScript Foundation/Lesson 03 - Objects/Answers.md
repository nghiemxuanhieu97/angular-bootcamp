## Câu 3
Object là gì? Hãy giải thích bằng ngôn ngữ của bạn.
-> là khái niệm đại diện cho một thực thể, đối tương, gồm các properties. Khi nói tới class thì thuộc tính của class đó sẽ là gọi là field, còn khi nói tới object thì thuộc tính được gọi là property
