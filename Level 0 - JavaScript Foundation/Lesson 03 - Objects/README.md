# Lesson 03 - Object

## Problem

Làm thế nào để gom nhiều dữ liệu liên quan thành một thực thể thay vì dùng hàng loạt biến riêng lẻ?

## Learning Objectives

- Hiểu Object được sinh ra để giải quyết vấn đề gì.
- Phân biệt variable, object, property và value.
- Biết hai cách truy cập property.
- Hiểu vì sao `const` vẫn có thể thêm/xóa property.
- So sánh Object trong JavaScript và Java.
- Liên hệ Object với Angular.
