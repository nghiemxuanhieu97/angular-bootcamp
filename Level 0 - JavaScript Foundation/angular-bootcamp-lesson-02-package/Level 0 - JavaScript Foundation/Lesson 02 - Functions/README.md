# Lesson 02 - Functions

## Problem
Làm thế nào để đặt tên cho một chuỗi hành động, tránh lặp code, chia nhỏ bài toán và trả kết quả cho nơi gọi?

## Learning Objectives
- Giải thích function bằng mental model.
- Phân biệt khai báo và gọi function.
- Phân biệt parameter và argument.
- Hiểu return value và `undefined` mặc định.
- Phân biệt `console.log()` và `return`.
- Hiểu function decomposition.
- Liên hệ Java method với JavaScript function.
- Biết khái niệm first-class function ở mức giới thiệu.
