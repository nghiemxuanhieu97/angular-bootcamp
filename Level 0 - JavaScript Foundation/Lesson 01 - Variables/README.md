# Lesson 01 - Variables

## Problem
Máy tính lưu và truy cập dữ liệu như thế nào, và vì sao JavaScript cần `var`, `let`, `const`?

## Learning Objectives
- Giải thích biến bằng mental model vùng nhớ.
- Phân biệt declaration, assignment, initialization và reassignment.
- Phân biệt `var`, `let`, `const`.
- Giải thích block scope.
- Hiểu vì sao JavaScript hiện đại hạn chế `var`.
- Hiểu vì sao ưu tiên `const`.
- Giải thích `const` với object và liên hệ với `final` trong Java.
- Hiểu vì sao class field trong Angular không viết `let` hoặc `const`.
