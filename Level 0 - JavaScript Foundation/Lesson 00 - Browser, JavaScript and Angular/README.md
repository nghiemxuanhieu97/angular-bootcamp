# Lesson 00 - Browser, JavaScript and Angular

## Problem
Website chỉ có HTML thì vì sao chưa đủ để tạo ra trải nghiệm tương tác?

## Learning Objectives
- Giải thích vai trò của HTML, CSS và JavaScript.
- Phân biệt browser và JavaScript Engine.
- Biết Chrome dùng V8, Firefox dùng SpiderMonkey, Safari dùng JavaScriptCore.
- Mô tả luồng Angular TypeScript → JavaScript → Browser → JavaScript Engine → UI.
- Hiểu vì sao Angular phụ thuộc vào JavaScript.

## Estimated Study Time
3–5 giờ

## Prerequisite
Không yêu cầu kiến thức frontend trước đó.
