# Lesson 06 - Spread & Rest

## Problem

Làm thế nào để trải các phần tử của Array/Object ra một cách ngắn gọn, và làm thế nào để gom nhiều argument thành một Array?

## Learning Objectives

Sau lesson này, người học có thể:

- Giải thích Spread được sinh ra để giải quyết vấn đề gì.
- Giải thích Rest được sinh ra để giải quyết vấn đề gì.
- Dùng Spread để nối hoặc sao chép Array.
- Dùng Rest trong function parameter.
- Phân biệt Spread và Rest dù cùng dùng cú pháp `...`.
- Liên hệ Rest với Varargs trong Java.
- Hiểu cách dùng Spread phổ biến trong Angular.
- Ghi nhớ: Spread trải ra, Rest gom lại.
