# Lesson 05 - Destructuring

## Problem

Làm thế nào để lấy nhiều giá trị từ Object hoặc Array mà không phải viết lặp lại nhiều câu lệnh truy cập property hoặc index?

## Learning Objectives

- Hiểu Destructuring được sinh ra để giải quyết vấn đề gì.
- Viết Object Destructuring và Array Destructuring.
- Hiểu Object Destructuring lấy giá trị theo tên property.
- Hiểu Array Destructuring lấy giá trị theo vị trí index.
- Biết bỏ qua phần tử trong Array Destructuring.
- Hiểu missing property có thể cho kết quả `undefined`.
- Nhận biết rename, default value, nested và rest destructuring.
- Hiểu Destructuring là cú pháp của ES6 giúp code rõ ràng hơn.
- Liên hệ Destructuring với Function và Angular.
