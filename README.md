# 1. Introduction

Angular Bootcamp is a complete learning repository designed to teach Angular from first principles.

Instead of memorizing syntax, learners understand:

- Why a concept exists
- What problem it solves
- How it compares with Java
- Where Angular uses it
- How to build a correct mental model

# 2. Goals

After finishing the Bootcamp, learners should be able to:

- Read modern JavaScript confidently.
- Write maintainable TypeScript.
- Understand Angular architecture.
- Build production-style Angular applications.
- Continue learning advanced Angular independently.

# 3. Target Audience

- Java Backend Developers
- Developers new to Frontend
- Self learners
- Team mentors

# 4. Learning Philosophy

Every lesson follows:

Story → Problem → Why → Mental Model → Syntax → Java Comparison → Angular Usage → Questions → Review

Important principles:

- Understand before memorizing.
- Storytelling is mandatory.
- Compare with Java whenever useful.
- Learn deeply only when it benefits Angular.
- Learner answers are preserved exactly.
- Review focuses on thinking, not only correctness.

Each lesson package contains:

- README.md
- Theory.md
- Questions.md
- Answers.md
- Review.md

# 9. Learning Modes

Fast Mode

- Finish one lesson end-to-end.

Deep Mode

- Re-code examples.
- Predict outputs.
- Teach back the lesson.
- Review after 1 day / 1 week / 1 month.

# 10. Design Principles

- Timeless documentation
- Problem-driven learning
- Java-first comparison
- Angular-oriented
- Reusable by future learners
- No learner-specific content

# 11. FAQ

Q: Can I skip JavaScript?
A: No. Angular is built on TypeScript, which compiles to JavaScript.

Q: Can I skip Storytelling?
A: No. Storytelling is part of the learning model.

Q: Where is learner progress?
A: PROGRESS.md.

# 12. Contributing

When extending the Bootcamp:

- Preserve lesson structure.
- Preserve storytelling.
- Preserve learner answers.
- Do not reduce lesson packages.
- Update Knowledge Graph and Roadmap when curriculum changes.
